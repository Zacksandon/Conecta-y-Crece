# Conecta y Crece
Proyecto para conectar emprendedores, mentores e inversores.

## Configuración
1. Inicia XAMPP y MySQL.
2. Crea la base de datos con `db/conecta_crece.sql`.
3. Instala dependencias: `pip install -r requirements.txt`.
4. Ejecuta la API: `python backend/api_conecta_crece.py`.

## Uso
- API en `http://localhost:5000`.
- Frontend en `frontend/html/`.
